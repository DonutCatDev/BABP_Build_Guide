# BABP Assembly Guide

This guide walks through the complete BABP build, from selecting a configuration to final assembly and maintenance. It was adapted from the baseline **BABP Assembly Instructions V0.1** and preserves the source photography alongside web-friendly instructions.

!!! warning "Build responsibly"
    Read each section before starting it. Wear appropriate eye protection, keep springs and pressurized components pointed in a safe direction, and follow all laws and event rules that apply where you live.

## Before You Begin

1. Review the [customization options](assembly/customization-options/index.md) and choose compatible variants.
2. Use the [master materials catalog](materials/index.md) for identification, then use each assembly's materials page for quantities.
3. Print and prepare all selected parts. Remove supports, clear holes, and test-fit interfaces before applying adhesive or threadlocker.
4. Work through the assemblies in the order below. Keep completed sub-assemblies organized for final assembly.

## Recommended Build Order

1. [Stock/Magwell](assembly/stock-magwell/index.md)
2. [Shroud](assembly/shroud/index.md)
3. [Gear Tensioner](assembly/gear-tensioner/index.md)
4. [Receiver](assembly/receiver/index.md)
5. [Prime Block](assembly/prime-block/index.md)
6. [Core](assembly/core/index.md)
7. [Loader](assembly/loader/index.md)
8. [Turnaround](assembly/turnaround/index.md)
9. [Final Assembly](assembly/final/index.md)

## After Assembly

- Use [Troubleshooting](assembly/troubleshooting/index.md) when a mechanism does not move or seal as expected.
- Review [Tuning and Maintenance](assembly/tuning-maintenance/index.md) before changing spring, seal, or lubrication choices.

## About This Guide

The baseline document is authoritative where this site does not yet provide an answer. Reference images on material cards are contextual images taken from that document; some show several related parts rather than an isolated component.
